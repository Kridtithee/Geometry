# 📐 สูตรเรขาคณิต (เว็บส่วนตัว)

ไฟล์ทั้งหมดเป็น HTML/CSS/JS ล้วน ไม่ต้อง build ไม่ต้องติดตั้งอะไร

| ไฟล์ | หน้าที่ | แก้เมื่อ |
|---|---|---|
| `index.html` | โครงหน้า + แท็บ "จำง่าย" | อยากแก้ข้อความเทคนิคจำ |
| `style.css` | สี/ฟอนต์/หน้าตา | อยากเปลี่ยนโทนสี (ตัวแปรบนสุดของไฟล์) |
| `data.js` | **สูตรทั้งหมด** 20 สูตร + ตัวเลือกหลอก + เคล็ดลับ | เพิ่ม/แก้สูตร |
| `shapes.js` | วาดรูปทรง SVG | เพิ่มรูปทรงใหม่ |
| `formulas.js` | แท็บสูตร + หน้าต่างทดลอง + โหมดท่องจำ | แก้การทำงานหน้าสูตร |
| `anim.js` | แท็บภาพเคลื่อนไหว | เพิ่มแอนิเมชัน (เพิ่มอีก 1 ออบเจ็กต์ใน `ANIMS`) |
| `game.js` | เกม 4 โหมด + สถิติทบทวนข้อที่พลาด | แก้จำนวนข้อ (`ROUND`) / รูปแบบโจทย์ |
| `main.js` | สลับแท็บ + เริ่มระบบ | ไม่ค่อยต้องแก้ |

## ทดลองในเครื่อง
ดับเบิลคลิก `index.html` ได้เลย

## อัปขึ้น GitHub Pages
### วิธีที่ 1: สคริปต์ (ต้องติดตั้ง git และ gh แล้วรัน `gh auth login` ครั้งเดียว)
```bash
bash deploy.sh                 # ใช้ชื่อ repo เริ่มต้น geometry-formulas
bash deploy.sh ชื่อ-repo-ใหม่   # หรือตั้งชื่อเอง
```
รันซ้ำทุกครั้งที่แก้ไฟล์ = อัปเดตเว็บ (รอ 1-2 นาที)

### วิธีที่ 2: ทำมือผ่านเว็บ
1. github.com → New repository → ตั้งชื่อ เช่น `geometry-formulas`
2. Add file → Upload files → ลากไฟล์ทั้ง 8 ไฟล์ (ไม่ใช่โฟลเดอร์) → Commit
3. Settings → Pages → Branch: `main` / `/ (root)` → Save
4. เปิด `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

## เรื่อง "ใช้คนเดียว"
- GitHub Pages ของ repo **private** ใช้ได้เฉพาะแผนเสียเงิน (Pro ขึ้นไป) แผนฟรีต้องเป็น repo public
- เว็บนี้ใส่ `noindex` ไว้แล้ว (Google จะไม่ติดอันดับ) แต่ใครมีลิงก์ก็เปิดได้ ไม่ต้องตั้งชื่อ repo ให้เดาง่าย
- ไม่มีข้อมูลส่วนตัวในเว็บเลย สถิติการเล่นเก็บในเบราว์เซอร์เครื่องคุณเท่านั้น (localStorage)
- บนมือถือ: เปิดลิงก์ → เมนูเบราว์เซอร์ → "เพิ่มลงหน้าจอหลัก" จะใช้เหมือนแอป

## ถ้าแท็บใดแท็บหนึ่งว่าง
- เปิดเว็บแล้วจะมี **แถบแดงบนหน้าจอ** บอกชื่อไฟล์ที่โหลดไม่ได้ หรือ error + บรรทัดที่พัง
- สาเหตุที่เจอบ่อย: ไฟล์ชื่อไม่ตรง (เช่น `game.js` กลายเป็น `xxxx-game.js` ตอนดาวน์โหลด/อัปโหลด), อัปไม่ครบ 8 ไฟล์, หรือเบราว์เซอร์ยังจำไฟล์เก่า (กดรีเฟรชแรง ๆ / เปลี่ยนเลข `?v=2` ใน `index.html` เป็น `?v=3`)
- ชื่อไฟล์ใน repo ต้องตรงตามนี้ทุกตัว (ตัวพิมพ์เล็ก): `index.html style.css data.js shapes.js formulas.js anim.js game.js main.js`
